# GNOME Shell extensions

These are the exact system-wide extension directories captured from the
installed target. They are reference artifacts rather than upstream source
checkouts. The enabled set is controlled by the system dconf database in
`config/osmium-overlay/etc/dconf/db/osmium.d/00-osmium-extensions`.

The Dash2Dock pin/drag changes are recorded separately in
`patches/dash2dock-v92-pin-drag.patch`.
